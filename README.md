## Модуль read_transactions_from_excel_and_csv  
  
Этот модуль представляет функцию **read_file,** которая предназначена для считывания финансовых операций из файлов CSV и  Excel. Функция возвращает данные в виде списка словарей, что  удобно для дальнейшей обработки и анализа данных.  
  
### Установка  
  
Перед использованием убедитесь, что у вас установлена библиотека   
pandas, а также openpyxl для работы с Excel файлами. Вы можете   
установить их с помощью следующих команд:  
  
pip install pandas  
pip install openpyxl  
  
### Использование  
Функция   принимает путь к файлу в формате строки и возвращает список   
словарей, где каждый словарь представляет одну запись из файла.  Для CSV файлов используется метод pd.read_csv с указанием разделителя - "; " . Для Excel файлов используется метод pd.read_excel.  Если формат файла не поддерживается, выбрасывается ошибка ValueError.
```python  
import os  
import pandas as pd  
from typing import List, Dict, Any, Hashable  
  
def read_file(file_path: str) -> List[Dict[Hashable, Any]]:  
 """функция для считывания csv и xslx файлов""" 
 if file_path.endswith(".csv"): 
     data = pd.read_csv(file_path, sep=";") 
 elif file_path.endswith(".xlsx"): 
     data = pd.read_excel(file_path) 
 else: 
     raise ValueError("Формат файла не поддерживается: " + file_path)  
 return data.to_dict(orient="records")  
```  
### Пример использования функции  
```python  
base_dir = os.path.dirname(os.path.dirname(__file__))  
csv_path = os.path.join(base_dir, "data", "transactions.csv")  
excel_path = os.path.join(base_dir, "data", "transactions_excel.xlsx")  
csv_data = read_file(csv_path)  
excel_data = read_file(excel_path)  
print(csv_data)  
print(excel_data)  
```

## Модуль processing  
  
### Описание модуля  
  
Модуль processing предоставляет функции для работы с транзакциями, включая их фильтрацию по состоянию и сортировку по дате. Это полезно для управления списками транзакций и их упорядочивания по заданным критериям.  
  
**Функция filter_by_state(transactions: List[Dict], state: str = "EXECUTED") -> List[Dict]**  
  
Описание: Фильтрует список транзакций, возвращая только те, которые соответствуют заданному состоянию.  
Параметры:  
transactions: список словарей, содержащих транзакции.  
state: строка, указывающая состояние транзакций для фильтрации (по умолчанию "EXECUTED").  
  
Возвращает: список транзакций, отфильтрованных по заданному состоянию.  
  
**Функция sort_by_date(transactions: List[Dict], ascending: bool = False) -> List[Dict]**  
  
Описание: Сортирует список транзакций по дате.  
Параметры:  
transactions: список словарей, содержащих транзакции.  
ascending: логическое значение, определяющее порядок сортировки (по умолчанию сортирует по убыванию).  
  
Возвращает: отсортированный список транзакций.  
Выбрасывает: ValueError, если формат даты некорректен.  
  
### Тестирование

Проверяются различные состояния транзакций, такие как "EXECUTED" и "CANCELED".

## Модуль Generators  
  
Этот модуль содержит три функции-генератора, каждая из которых выполняет определенную задачу:  
  
  
 1. **filter_by_currency:** Фильтрует список транзакций, возвращая только те, которые соответствуют заданной валюте.  
  
 2. **generate_description**: Возвращает описания для каждой транзакции из предоставленного списка.  
  
 3. **card_number_generator:** Генерирует номера банковских карт в формате "XXXX XXXX XXXX XXXX" в заданном диапазоне.  
  
Примеры использования  
  
**Функция filter_by_currency**  
  
Эта функция принимает список транзакций и код валюты, по которому необходимо фильтровать. Она возвращает итератор с транзакциями, соответствующими указанной валюте.  
  
```python  
transactions = [  
 {"operationAmount": {"currency": {"code": "USD"}}}, {"operationAmount": {"currency": {"code": "EUR"}}}]  
  
for transaction in filter_by_currency(transactions, "USD"):  
 print(transaction)# Вывод: {'operationAmount': {'currency': {'code': 'USD'}}}  
```  
Если ни одна транзакция не соответствует указанной валюте, выводится сообщение "Валюта не найдена".  
  
  
**Функция generate_description**  
  
Эта функция принимает список словарей с транзакциями и возвращает итератор, который выдаёт описание каждой транзакции.  
  
```python  
transactions = [  
 {"description": "Перевод организации"}, {"description": "Перевод со счета на счет"}]  
  
descriptions = generate_description(transactions)  
for description in descriptions:  
 print(description)# Вывод:  
# Перевод организации  
# Перевод со счета на счет  
```  
  
**Функция card_number_generator**  
  
Функция генерирует номера карт в формате "XXXX XXXX XXXX XXXX" для чисел в заданном диапазоне.  
  
```python  
for card_number in card_number_generator(1, 3):  
 print(card_number)# Вывод:  
# 0000 0000 0000 0001  
# 0000 0000 0000 0002  
# 0000 0000 0000 0003  
```  
  
Этот модуль предоставляет удобные инструменты для работы с транзакциями и генерацией номеров карт, что может быть полезно в различных финансовых приложениях и системах. Использование функций-генераторов позволяет эффективно обрабатывать данные и минимизировать использование памяти.  
  
  
## Модуль Decorators c декоратором `log`  
  
`log` — это декоратор для Python, предназначенный для логирования выполнения функций. Он позволяет записывать информацию о выполнении функций в файл или выводить её в консоль.  
  
### Описание  
  
Декоратор `log` добавляет возможность логирования к любой функции, не изменяя её исходный код. Это удобно для отладки и мониторинга выполнения функций, особенно в больших проектах.  
  
### Установка  
  
Для использования декоратора просто скопируйте его код в ваш проект и импортируйте его в нужном месте.  
  

  
### Пример использования  
  
```python  
from your_module import log  
  
@log(filename="mylog.txt")  
def my_function(x, y):  
 return x + y  
my_function(1, 2)  
  
```  
  
В этом примере, каждый вызов `my_function` будет логироваться в файл `mylog.txt`.  
  
### Аргументы  
  
• **`filename`** : Имя файла для логирования. Если не указан, логи выводятся в консоль.  
  
### Функциональность  
  
• **Логирование успешного выполнения**: Записывает сообщение об успешном выполнении функции.  
  
• **Логирование ошибок**: В случае возникновения исключения записывает сообщение об ошибке с указанием типа ошибки и входных данных.  
  
### Пример вывода  
  
• При успешном вызове:  
```  
my_function ok  
```  
• При ошибке:  
```  
my_function error: TypeError. Inputs: (1, "a"), {}  
  
```  
### Тестирование  
  
Для проверки работы декоратора вы можете использовать `pytest` и фикстуру `capsys` для перехвата вывода в консоль. Также рекомендуется использовать `coverage.py` для измерения покрытия тестов.
